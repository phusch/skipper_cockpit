# Friesland Skipper Cockpit V0.11 – Nautikscan-Fix

Basiert ausschließlich auf V0.10. Nautikscan jetzt mit mehreren Overpass-Servern und automatischem Fallback. Die hochgeladene goldene Schiffsschraube ist als Logo eingebunden. Alle sieben Original-GPX und bestehenden Funktionen bleiben erhalten.

Wichtig: Bei direktem file://-Start kann der Browser externe Abfragen blockieren. Für den Online-Nautikscan die App über HTTPS/Webserver verwenden. Waterkaarten bleibt maßgeblich.
