# Friesland Skipper Cockpit V0.10 – Nautik in Fahrreihenfolge

V0.10 baut ausschließlich additiv auf V0.9 auf.

## Neu
- nautische Objekte werden nach ihrer Position entlang der echten GPX-Route sortiert
- Anzeige „bei ca. X km ab Tagesstart“
- neuer Block **„Was kommt als Nächstes?“**
- bei aktivem GPS wird das nächste vorausliegende nautische Objekt hervorgehoben
- Entfernung zum nächsten Objekt wird entlang der GPX-Route berechnet
- Brücke / Schleuse wird mit Icon, Status und vorhandenen Maßangaben dargestellt
- vorhandene Grün/Signalgelb/Rot-Bewertung bleibt unverändert konservativ

## Unverändert
- alle 7 Original-GPX-Dateien und deren Geometrie
- Karten, Fahrtrichtungspfeile, Wegpunkte
- GPS-Grundfunktion
- V0.9 OSM/Overpass Nautik-Scan
- Schiffsprofil Artemis / editierbare Profile
- Skipperbrief
- Tag-2-Wetter- und Tag-3-Zeitlogik
- Landgang, Nachtplätze, Waterkaarten
- Modern-Maritime Design
- kein Bordlogbuch / kein Reiseführer in dieser Stufe

## Sicherheitsprinzip
Waterkaarten, amtliche Meldungen und die Entscheidung des Skippers bleiben maßgeblich.
